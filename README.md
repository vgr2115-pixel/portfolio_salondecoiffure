# Maison Alba — portfolio salon de coiffure

Démonstration fictive réalisée par Vincent pour présenter un exemple de site de salon sans personnalisation préalable.

## Consulter
Ouvrir index.html dans un navigateur connecté à Internet. Aucun build ni dépendance JavaScript.
Pour servir localement : `python3 -m http.server 8766`, puis ouvrir http://localhost:8766/.

## Contenu
- Identité fictive Maison Alba ; palette sauge et crème.
- Accueil, galerie d'inspirations, esprit du salon, prestations et contact.
- Menu mobile, tarifs dépliables et fenêtres de démonstration de réservation.
- Mise en page responsive et prise en compte des préférences de mouvement réduit.
- Aucune collecte, aucun formulaire, aucune réservation réelle.
- Pas de faux avis, de fausse équipe ni de fausse adresse.
- Photographies externes Unsplash, polices Google Fonts : connexion Internet nécessaire.
- Tarifs et horaires illustratifs ; images d'inspiration, pas réalisations d'un client.
- Directive noindex,nofollow.

## Présenter à un commerçant
« Voici un exemple de ce que je peux réaliser pour un salon. Pour le vôtre, nous adapterions l'identité, les photos, les prestations et la réservation. »
Montrer accueil → inspirations → prestations → bouton de réservation.
Ce concept n'est pas une réalisation pour un client existant.

## Adapter pour un vrai salon
Remplacer identité, textes, photographies, prix, horaires et liens par des éléments validés.
Connecter le bouton à l'outil réellement utilisé ; ajouter les coordonnées et informations légales appropriées.
Vérifier droits des images, rendu mobile/ordinateur et parcours complet avant publication.
Le code peut servir de point de départ, mais la présentation doit être repensée pour chaque client.

## Vérifications effectuées
Ancres internes, unicité des identifiants et présence des textes alternatifs vérifiées.
Le contrôle visuel dans un navigateur et le chargement des ressources externes restent à vérifier.
Aucun hébergement public activé par cette modification.
